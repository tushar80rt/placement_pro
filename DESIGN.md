# DESIGN.md: Placement Preparation reference

## Source
- URL: https://www.placementpreparation.io/
- Capture date: 2026-07-31
- Evidence: page structure and visible content captured from the public homepage. Automated branding/screenshot capture was unavailable in this environment.

## Design Summary
A bright, friendly placement-prep landing page. It uses a spacious navigation bar, an oversized search-led hero, rounded content panels, compact topic chips, and repeated category grids to make a broad learning catalogue feel approachable.

## Design Tokens
### Colors
- Primary: warm coral `#ff6b57` (inspired, inferred)
- Ink: `#17202b`
- Muted text: `#667085`
- Canvas: `#fffaf7`
- Surface: `#ffffff`
- Soft coral: `#fff0ea`
- Border: `#f1e6df`

### Typography
- Clean geometric sans with a strong, dark display heading.
- Headings: 600–800 weight, tight tracking; body: 400–500 weight with generous line height.

### Spacing and Layout
- Content width: about 1180px.
- Large hero vertical spacing, 16–24px card gaps, 18–24px corner radii.
- Use soft tinted panels and subtle borders rather than heavy shadows.

## Components
- Sticky top navigation with text links, a quiet login affordance, and a pill-shaped primary CTA.
- Search bar centered in the hero with an icon and primary action.
- Rounded topic chips, icon-led feature cards, category tabs, logo/name cloud, FAQ rows, and an end-of-page CTA.

## Page Patterns
1. Navigation and announcement strip
2. Search-centered hero with topic chips and quick proof points
3. Essential learning areas grid
4. Feature category explorer
5. Company preparation list
6. CTA and footer

## Agent Build Instructions
Create an original landing page inspired by the above hierarchy. Do not reuse the reference’s brand assets, logos, copy, or exact illustrations. Preserve a light, optimistic aesthetic and prioritize scan-friendly grouping of placement resources.
